# 플랫폼 Smoke Test

DEVELOPMENT.md 18.5의 릴리스 수동 점검 목록이다. macOS와 Windows의 release-equivalent
패키지에서 각각 수행한다. 각 항목은 "완료 정의"(20장)를 만족해야 통과다.

## 준비

- [ ] 서명·notarize된 설치 파일로 클린 머신에 설치
- [ ] 첫 실행 시 네트워크 고지가 뜨고, 수락 전에는 어떤 API 키도 요구하지 않음
- [ ] 콜드 스타트 3초 이내 (§4.1)

## 자격증명

- [ ] OpenAI 또는 Anthropic 키 입력 시 실제 공급자에 검증되고, 잘못된 키는 키를 노출하지 않는 오류를 표시
- [ ] 키 저장 후 앱을 재실행해도 다시 입력을 요구하지 않음 (OS 키체인)
- [ ] 키 삭제 시 로컬 기능은 그대로, AI 작업만 대기 상태로 전환

## 가져오기와 라이브러리

- [ ] 파일 선택창과 드래그 앤 드롭으로 여러 PDF 가져오기
- [ ] 같은 파일을 다시 가져오면 중복으로 인식하고 복사본을 만들지 않음
- [ ] 손상·암호화 PDF는 원인과 다음 행동을 설명하며 거부, 임시 파일이 남지 않음
- [ ] 목록/아이콘 전환이 재실행 후에도 유지
- [ ] 그룹·태그·연도·상태·즐겨찾기 필터와 정렬이 동작
- [ ] 논문 삭제 시 하이라이트·분석·관리 PDF가 함께 정리됨

## 처리 파이프라인

- [ ] 가져오기 직후 추출→색인→분석 상태가 아이콘·텍스트로 표시됨
- [ ] AI 분석 도중 앱을 강제 종료한 뒤 재실행하면 작업이 재개됨 (§10.1)
- [ ] 텍스트 레이어가 없는 스캔 PDF는 "일부 완료"로 열람만 가능
- [ ] 임베딩 모델이 최초 사용 시 자동 다운로드되고, 실패 시 재시도 action 제공

## 뷰어

- [ ] PDF 렌더링, 연속 스크롤, 페이지 이동, zoom, 썸네일
- [ ] 텍스트 선택 후 5색 하이라이트 생성·색상 변경·삭제
- [ ] 하이라이트가 zoom·회전·재실행 후 같은 위치에 유지
- [ ] 현재 페이지 번역 실행 → 페이지 전체가 한 번의 요청으로 번역되어 표시 (수 초 내)
- [ ] 문단/전체 토글 전환이 재번역 없이 즉시 이루어짐 (같은 번역 결과를 다르게 배치)
- [ ] 전체 보기는 페이지 번역문을 한 덩어리로, 문단 보기는 문단별로 나눠 표시
- [ ] 2단 편집 논문에서 좌·우 단이 섞이지 않고 각 단이 순서대로 번역됨
- [ ] 번역문의 문장에 hover 시 원문 rectangle 강조, click 시 원문으로 이동
- [ ] 페이지를 바꾸면 번역 패널도 해당 페이지로 전환
- [ ] 한국어가 아닌 논문은 열자마자 첫 페이지가 자동 번역되고, 한국어 논문은 자동 번역하지 않음
- [ ] 다음 페이지로 넘어가기 전에 미리 번역이 준비되어 즉시 표시됨 (prefetch)
- [ ] 텍스트를 드래그하면 툴바에 하이라이트 색상과 "번역" 버튼이 함께 표시
- [ ] "번역"을 누르면 선택 영역만 번역되어 툴바 아래 팝오버로 표시, 새로 드래그하면 팝오버가 사라짐

## AI 정리

- [ ] 분석 탭에 요약·연구 문제·기여점·방법론·결과·한계가 정리됨
- [ ] 기여점·결과의 페이지 링크를 누르면 해당 페이지로 이동
- [ ] 근거가 없는 항목은 지어내지 않고 "확인되지 않음"으로 표기

## 검색과 채팅

- [ ] floating 채팅 버튼이 우하단 고정 위치에 표시
- [ ] 논문/그룹/라이브러리 scope로 질문
- [ ] 답변이 streaming으로 표시되고 중지 가능
- [ ] 사실 주장에 출처 chip이 붙고, 클릭 시 해당 논문·페이지로 이동
- [ ] 근거가 부족하면 부족하다고 답함
- [ ] 임베딩 모델 다운로드 중에도 키워드 검색은 동작

## 그래프

- [ ] 의미 유사·인용·직접 연결 관계가 표시됨
- [ ] 녹색은 활성 선택에만, 나머지는 grayscale·opacity로 구분
- [ ] zoom·pan·fit, 그룹·관계 유형 필터
- [ ] 노드 double click 시 논문 열기
- [ ] reduced motion에서 force-layout 애니메이션 미사용

## Obsidian

- [ ] Vault 폴더 선택 후 분석된 논문이 Bbrain/Papers에 노트로 생성
- [ ] 노트의 사용자 영역·알 수 없는 frontmatter·섹션이 재동기화 후에도 보존
- [ ] Vault에서 태그·그룹을 바꾸면 앱에 반영
- [ ] Obsidian에서 노트를 삭제해도 앱의 논문은 삭제되지 않음
- [ ] managed marker가 손상된 노트는 conflict로 표시하고 자동 덮어쓰기 중지
- [ ] 관련 논문이 일반 wiki link로 기록되어 Obsidian Graph View에 나타남

## 데이터 보존과 보안

- [ ] update 또는 reinstall 후 라이브러리·하이라이트·노트가 유지됨
- [ ] 로그에 API 키, authorization header, 논문 본문이 남지 않음 (§16.1)
- [ ] 키보드 내비게이션과 visible focus ring 동작
